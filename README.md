## 📌 Overview

A lightweight, file-persistent **To-Do List CLI application** written in pure C. Manage your tasks from the terminal with a clean menu-driven interface.

---

## ✨ Features

| Feature | Description |
|---|---|
| ➕ Add Tasks | Create new tasks with a title |
| 📋 View Tasks | Display all tasks with their status |
| ✏️ Edit Tasks | Modify existing task details |
| 🗑️ Delete Tasks | Remove tasks permanently |
| ✔️ Mark Complete | Mark tasks as completed |
| 💾 Save to File | Persist tasks across sessions |
| 📂 Auto Load | Tasks load automatically on startup |
